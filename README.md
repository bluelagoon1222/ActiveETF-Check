# Active ETF CHECK (액티브 ETF CHECK)

국내 주식형 **액티브 ETF**를 같은 섹터끼리 한 페이지에서 비교하는 사이트입니다.

- 전일 대비 **신규 편입 / 제외 / 비중 변화** 표시
- 구성종목 옆에 **비교지수 대비 초과·과소 비중** 표시 (매니저 뷰)
- 같은 그룹 ETF의 **성과 비교** (1D~1Y, 종가/NAV, 지수 대비 초과수익)
- 같은 그룹 ETF의 **구성종목 비교 매트릭스** (공통보유 / 단독보유 / 전일 변동 필터)
- 매 영업일 18:40 KST GitHub Actions가 KRX 데이터를 수집해 자동 갱신

## 구조

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 (data/latest.json 을 읽어 표시) |
| `scripts/collect.py` | KRX 정보데이터시스템에서 ETF 목록·시세·PDF·지수구성종목 수집 및 계산 |
| `scripts/make_sample.py` | 인터넷 없이 화면 확인용 샘플 데이터 생성 (테스트용) |
| `.github/workflows/update.yml` | 평일 18:40 / 21:10 KST 자동 실행, 수동 실행 가능 |
| `data/latest.json` | 화면용 최종 데이터 |
| `data/history.json` | ETF별 종가·NAV·지수 일별 이력 |
| `data/pdf/YYYYMMDD.json` | 일별 PDF 스냅샷 (최근 70영업일 보관) |
| `data/status.json` | 마지막 수집 성공/실패 상태 |

## 데이터 출처 / 주의
- 한국거래소 정보데이터시스템 (data.krx.co.kr) — ETF 기본정보, 전종목 시세, 구성종목(PDF), 지수 구성종목
- 지수 비중은 지수 구성종목의 시가총액 가중 근사치(유동비율 미반영)입니다. 지수를 찾지 못하면 동일 지수 패시브 ETF의 PDF를 대용합니다.
- 수익률은 종가 또는 NAV 단순 등락률이며 분배금은 반영하지 않습니다.
- 본 사이트는 공시 데이터를 정리한 참고자료이며 투자 권유가 아닙니다.
